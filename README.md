# Examine — AI Exam Preparation Platform

**প্রোডাক্ট:** Examine
**MVP ফোকাস:** শুধু পেট্রোবাংলা চাকরির প্রস্তুতি (একটি ক্যাটাগরি)
**স্ট্যাটাস:** পরিকল্পনা ও ডকুমেন্টেশন পর্যায় — প্রথম দুটি ডকুমেন্ট তৈরি: `docs/01-product-requirements.md` ও `docs/02-system-architecture.md`
